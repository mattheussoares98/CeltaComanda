> ## FLUXO
## CONSULTA DA COMANDA
# PADRÃO
1. Exibir o loading ao iniciar a consulta da comanda

# SUCESSO
1. Exibe os grupos expansíveis para selecionar
2. ✅ Esconder o loading no término da consulta

# FALHA
1. Mostra mensagem de comanda não disponível
2. ✅ Esconder o loading no término da consulta
3. Permite a consulta de outra comanda

## CONSULTA DOS GRUPOS EXPANSÍVEIS
# PADRÃO
1. ✅ Exibir o loading ao iniciar a consulta dos grupos

# SUCESSO
1. ✅ Ao clicar no grupo expansível, deve levar pra tela dos produtos que fazem parte do grupo expansível
2. ✅ Esconder o loading no término da consulta

# ERRO
1. ✅ Exibir mensagem de erro caso ocorra erro pra consultar os produtos
2. ✅ Esconder o loading no término da consulta
3. ✅ O usuário deve conseguir consultar os grupos expansíveis novamente em caso de erro na consulta dos grupos
