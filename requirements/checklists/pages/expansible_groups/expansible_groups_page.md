# Expansible Groups Page

> ## Regras
1. ✅ O usuário deve conseguir consultar os grupos expansíveis novamente em caso de erro na consulta dos grupos
2. ✅ Ao clicar no grupo expansível, deve levar pra tela dos produtos que fazem parte do grupo expansível
3. ✅ Exibir o loading enquanto estiver consultando os produtos
4. ✅ Ao clicar no ícone do carrinho, levar pra tela de totalização 
5. ✅ Exibir mensagem de erro caso ocorra erro pra consultar os produtos
6. ✅ Esconder loading no fim da ação de consulta
